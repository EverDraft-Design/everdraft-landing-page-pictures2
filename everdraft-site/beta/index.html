Testing Checklist

Account Setup

  • Try this: create an account at signup.
  • Set your username and check it feels right before saving.
  • Add or edit your display name, pen name, role, and short bio.
  • Return to your account page and sign back in later.

Writer Test Flow

  • Create a new story from My Stories.
  • Add a cover image URL if you have one handy.
  • Add or edit the story blurb, genre, and details.
  • Add a chapter from the story editing page.
  • Save a chapter as draft, then try changing it to published.
  • View the private story preview and check the chapter order feels clear.
  • Notice anything confusing in the writer flow? Send feedback.

Reader Test Flow

  • Visit the reader-facing pages available to your test account.
  • Open a story or preview and check whether the reading path feels calm.
  • If Library, follows, Sparks, Reader Notes, or public chapter pages are open for your test, try each one.
  • Return to the story page, then return to the Library or account page.
  • Send feedback if something feels odd, missing, or hard to find.

Navigation Test

  • Use only on-page buttons and links to move around.
  • Check this feels clear without needing the browser back button.
  • Try Back to Account, Back to My Stories, Back to Story, Chapters, and Return to Library links wherever they appear.

Mobile Test

  • Try the same flow on mobile or a narrow browser window.
  • Check buttons, cards, forms, and reading pages are easy to use.
  • Notice anything that feels cramped or confusing? Please send a note.

FEEDBACK

Found something odd?

If something breaks, feels confusing, or you have a question, email hello@everdraft.net. Thoughtful feedback helps EverDraft grow softer, safer, and easier to use.
